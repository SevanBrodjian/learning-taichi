## Why there was a rework
Sevan sent T-027 back with one note: *"The water did not get its rendering updated, it's still the
old version. Use either of the new proposed appearances for water, whichever one is more efficient."*

He was right, and the diagnosis is the interesting part. The first run **did** port T-020's water
option B — the shading. It did not port the **reconstruction** the shading reads, so optical
thickness and the normal still came off four local taps of the raw splat accumulation, which is
lumpy at the particle scale. The lighting model was correct and was correctly lighting the wrong
surface. Nothing about that is visible in a code review; it is only visible in the picture.
