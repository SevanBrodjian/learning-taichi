# Notebook

Sevan's thinking space. Slow-moving, semi-structured, high-level: where his head is at, what he is
interested in, where he wants to take things, ideas worth trying, sketches and diagrams.

**Hand-written by Sevan. The agent reads it and never edits it.** Reading it is genuinely useful — it is
the best signal for what work to propose — but tidying it would defeat the point. A scratchpad someone
else has organised is not a scratchpad any more.

## How it is meant to work
- **One living document**, `current.md`, edited freely and continuously. Not a blog, not dated entries
  you must not touch again. Git supplies the real history, so overwriting a paragraph loses nothing.
- **Semi-structured**: keep loose headings so it stays navigable, but there is no schema and nothing is
  required. If a section stops being useful, delete it.
- **Images and sketches** live in `media/` and get referenced with normal markdown. Photograph a piece of
  paper if that is faster — the agent can look at it.
- Edited in the dashboard (Notebook tab) or in any editor. It is just markdown on disk.

## Why it exists
The task board records what was *done*. The training textbook records what is *known*. Neither records
what Sevan is *thinking* — the half-formed intent that decides what gets built next, and the only part
that does not survive in git unless it is written down somewhere.

It is also the handover document. When this project is picked up later, or a new one starts from this
harness, `current.md` is what explains why any of it was worth doing.
